# Content setup

The default concept collection contains Form (leggings), Muse (studio bra), Flow (biker shorts), and Ease (tank). These are illustrative names, not actual Shopify product records. No composition, technical performance, size measurements, reviews, discounts, prices or stock have been invented.

Before selling: create verified products with photos, pricing, sizes, inventory and shipping details; place them in a collection and select it in the homepage editor. Configure product metafield `custom.fabric_care` with an appropriate rich text or text type. Select a real size-guide page. Images should include meaningful alt text. Select menus and the contact page in header/footer settings. Optional Instagram URL is blank until configured.

Home sections: Editorial hero (desktop/mobile image), Manifesto, Collection edit, Movement story (image and destination), MUSA Club. Sections can be rearranged, removed and added in Shopify's theme editor. Global palette is configurable.

MUSA Club is an email community, not a loyalty or paid program. The newsletter uses Shopify's customer form and requires explicit consent. Configure welcome automation separately if desired and verify delivery. No shipping, return or privacy policy is fabricated; footer policy links appear only for populated Shopify policies.

The local design preview demonstrates English and Spanish using sample illustrations. Forms and shopping navigation are clearly disabled in the preview. The actual theme uses native Shopify forms and catalog routes.
