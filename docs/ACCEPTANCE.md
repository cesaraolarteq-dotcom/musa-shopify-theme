# Acceptance checklist

Local verification covers Theme Check, JSON/schema/reference validation, JavaScript syntax, actual variant/menu interaction in Chromium, bilingual preview rendering, responsive layout, and ZIP integrity. These checks do not prove server-side Shopify rendering.

Authenticated store checks still required:
- Upload as a new unpublished theme; verify JSON templates and theme editor.
- Publish English and Spanish; verify language switch, Markets/currencies and translated merchant content.
- Select a real catalog: featured collection, filters, sorting, pagination, product media, all variants and sold-out behavior.
- Add actual variants to cart, update/remove quantities, verify line properties and discounts, test checkout with store-supported test payments.
- Validate newsletter success/error, consent, customer tags, contact delivery, and privacy policies.
- Check actual campaign images/alt text, mobile devices, keyboard operation, apps, account links and SEO metadata.
- Merchant review before publication. Do not publish without explicit approval.
